## Findings and verdicts

### F-01 [stage-1, high] Swap trusts the server's folder layout: **Fix now**

`deploy/plan.ts:334` treats a clash with a protected file only when the paths are exactly
equal. `deploy/remote/swap.sh:46-48` runs `mkdir -p` and `mv -f` without checking what is
already at the address. The reviewer reproduced three cases:

- A build file `x` where the server has a protected `x/x`: `mv` writes into the folder and
  overwrites the protected file.
- A symlinked parent (`_astro -> ../outside`): files are written outside the site folder.
- A file where the build needs a folder: the run fails halfway through the renames.

Fix:
- Planner stop-guard for parent/child clashes between a build path and a listed path.
- `swap.sh` refuses when the target is a folder or any parent is a symlink.
- New `plan.test` and `swap.test` cases for each.

### F-03 [stage-1/2] Worker failure paths and record drift: **Fix now**
