## Findings and verdicts

### G8-01 [stage-2, medium] `readFlat` is quadratic on a tag name that contains `<`: **Fix now** (T36)

`src/lib/offsite-requests.ts:103, :321, :328`. `TAG_NAME` has no length limit since T34 and lets a name run through `<`;
`readFlat` advances one character, so every `<` rescans the run. `"<a".repeat(50000)` (100 KB) takes 2.06 s (pre-T34 16 ms),
200 KB takes 8.3 s, about 14 minutes extrapolated to 1 MB; `<a"`, `<a=` and `<svg<` behave the same. Breaks T34's DoD
(slowest 1 MB input under 1 s); the linear-time test has no such input. A regression introduced by T34.

### G8-02 [stage-1 + stage-2, medium] The region-free pass loses a tag with a quoted `>` or `<` before its fetching attribute: **Fix now** (T36)

`src/lib/offsite-requests.ts:331-337` (`limit = min(gt, nextLt)`), comment `:299-303`, `spec.md:244`. The pass cuts a tag at the
first raw `>` or `<` even inside quotes, so it does not "bound any desync to that tag". When the four readings are out of
sync, `<svg><style><img alt="a > b" src="https://t.example.com/p.png"></style></svg>` returns `[]` at HEAD and at `c4a5f84`;
pre-T31 reports it and parse5 fetches it (44 of 210 combinations missed at HEAD; 22 of 60k fuzz inputs). Astro writes
`alt={"a < b"}` with a raw `<`; the out-of-sync context is unrealistic (same standing as F7-01). Spec §8 R6-02 is reopened.
Fix on record: the pre-T31 global attribute scans as a sixth member.

### G8-03 [stage-2, low] The flat pass is less careful than `readMarkup`: **Fix now** (T36)

`src/lib/offsite-requests.ts:314-316, :322-326, :341-357`. (a) One counter for `<svg>` and `<math>`, and `html[gt-1] === "/"`
for self-closing (the defects T33/T34 fixed in `readMarkup`). (b) With no `</style` the flat run decodes to the end of the page:
`<svg><style>.a{}</svg><p>url(&quot;https://x.example.com/a.png&quot;)</p>` is a new false positive. (c) The `<svg>` count includes
`<svg>` in scripts and comments, and attribute values holding markup are reported. The documented trade-off names only
commented-out tags and script strings (also stage 1, `:303-305`, `spec.md:244`). All fail the build, never the visitor.

### G8-04 [stage-1 + stage-2, medium/low] Six mutants survive; T35 status and total are stale: **Fix now** (T36, T37)

`tests/offsite-requests.test.ts:553-716`. Surviving mutants that hide a request: 63-character tag-name limit, `noStyleEnd` always
true in `readMarkup`, `styleDone = html.length`, case-sensitive `style` in `readFlat`, `foreign > 1`, and decoded values from the
first reading only (`:383`). `tasks/t35-docs-sync-6.md:10, :21-33` is still `todo` and unticked; the tracker total should be
about 16.4 d, not 16.3 (the rows give 21 S × 0.3 + 13 M × 0.7 + 1 d).
