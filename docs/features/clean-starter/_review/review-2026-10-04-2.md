## Findings and verdicts

### R-01 [stage-1, high] Off-site guard misses entity-encoded `url()` in style attributes: **Fix now** (T24)

`src/lib/offsite-requests.ts:49-53`, `:11`; spec §6 NFR (third-party requests 0). Astro writes
`style="background-image:url(&quot;https://bg.example.com/z.jpg&quot;)"`. The captured value starts with
`&quot;`, so `isOffSite` doesn't match it and `tests/build.test.ts:89-101` passes with a live
third-party request. Reproduced in a scratch build. Fix: decode entities before matching; unit case
with Astro's exact output.

### R-02 [stage-1] AC-03 build test compares two empty lists: **Fix now** (T25)

`tests/build.test.ts:76-86`; AC-03. `src/pages/` has no section pages, so `expected` and `offered` are
both `[]`; a header with no links passes. The remaining part of F-05. Fix: a fixture build with a
planted section page, asserting a non-empty ordered `{label, href}` list.

### R-03 [stage-1] `layout-clash` stops on an unknown file, contradicting AC-13 and §6.1: **Fix now — spec amended**

`deploy/plan.ts:356-366, 401-407`; `tests/plan.test.ts:484-497`; `deploy/remote/swap.sh:50-65`;
`spec.md` AC-13, §6.1. The maintainer chose to keep the stop: it is the only safe behaviour, since the
build can't write there without touching the file. Done in this review: new AC-13b
(`<!-- added-by-fix -->`), AC-13 and §6.1 now point to it. Mirroring into sad/data-model is T26.

### R-04 [stage-1] Docs lag the code: **Fix now** (T26)

- `data-model.md:192`: "owned / approved + inBuild → overwrite" is wrong for approved paths
  (`deploy/plan.ts:394-400` stops with `approved-in-build`); `layout-clash` (listed at ~269) has no rule.
- `sad.md:288, 729`, ADR-0005 `:37`: CODEOWNERS described as `deploy/` + `.github/` only; the enforced
  rule is every file loaded while `SSH_PRIVATE_KEY` is set (`.github/CODEOWNERS:5-7`,
  `tests/workflow.test.ts`).
- `sad.md:355-369, 493-503`: Flows 1 and 5 lack `failed-before-swap` / `failed-during-swap` with the
  re-sealed report and public summary (`deploy/publish.ts:321-361`, `data-model.md:261`).

### R-05 [stage-2, medium] `swap-seconds` includes the pre-check: **Defer** (§8)

`deploy/remote/swap.sh:45, 50-65`; NFR mixed-version window ≤ 5 s. `start=$(now)` runs before step 0,
which forks `dirname` per folder level. Fix later: start the timer after step 0; use `${d%/*}`.

### R-06 [stage-2, medium] A failed record read drops owned leftovers: **Defer** (§8)

`deploy/publish.ts:239-241`, `deploy/plan.ts:408-416`; data-model carry invariant. Any non-0/7 exit
(I/O, missing `cat`, dropped SSH) counts as `unreadable`; with deletion off the run goes on with an
empty carry and the new record forgets the owned leftovers. Fix later: stop with `listing-failed`; add
`cat`, `sh`, `date` to the probe.

### R-07 [stage-2, medium] Mid-swap failure leaves files in no record: **Defer** (§8)

`deploy/remote/swap.sh:67-96`, `deploy/README.md:37`, ADR-0003. Files already moved are not in any
record; if the next build's asset hashes differ they read as unknown for good. Fix later: provisional
record before step 1, plus a two-publish test.

### R-08 [stage-2, medium] Code-owner import walk misses import forms: **Defer** (§8)

`tests/workflow.test.ts:69-77`; AC-08, ADR-0005. `export … from`, side-effect `import "…"` and dynamic
`import()` are neither followed nor flagged, despite commit `1751f67`. Today's graph is covered. Fix
later: match those forms and throw on any relative or `#` specifier it can't resolve.

### R-09 [stage-2, low] Hardening batch: **Defer** (§8)

- Off-site scanner (`src/lib/offsite-requests.ts:9-56`, `tests/build.test.ts:96`): misses `object data`,
  `feImage`, `imagesrcset`, `image-set()`, `<base href>`, `<img/src=…>`, `/\host`, `http:/host`; built

  rejected by the rules parser (`deploy/plan.ts:78`); build paths that clash with the worker's own
  files not rejected (`deploy/plan.ts:374-377`).
- Tests that don't test the failure they name: `tests/publish.test.ts:365` (swap.sh exit 5 never
  reached), `:422` (always-true warning match), `:453-480` (faked probe output).
