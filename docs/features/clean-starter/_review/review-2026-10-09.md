## Findings and verdicts

### H9-01 [stage-1 + stage-2, medium] The legacy scan loses `src`/`poster`/`srcset` after a bare or unquoted attribute: **Fix now** (T38)

`src/lib/offsite-requests.ts:396-409` (`(?<=["'])\s+`), comment `:396-401`, `spec.md:244`, `tasks/t36-…md:25`. T36 planned the scans
"after whitespace" so that additivity to pre-T31 holds by construction; the code matches only right after a closing quote
(to keep escaped page text unreported). In a page the four readings misread, with a quoted `>` or `<` cutting the flat pass,
a bare or unquoted attribute before `src` hides it: `<svg><style><img alt="a > b" hidden src="https://t.example.com/p.png"></style></svg>`
returns `[]` at HEAD and at 14083eb; pre-T31 reports it and parse5 fetches it (75 of 200k fuzz inputs; all other misses were
the documented `<link>`/`<image>` quoted-`>` residual). Astro writes boolean attributes bare (`hidden src=…`), so the
attribute shape is realistic; the out-of-sync context is not. The comment "Astro quotes every attribute" and "no region,
quote or `>` before it can hide it" are false. A `style` attribute after a quoted `>` is a second residual that pre-T31 also missed.
R6-02 is reopened.

### H9-02 [stage-2, medium/low] The tests miss mutants of the T36 code, and two rows pin a request nobody makes: **Fix now** (T38)

`src/lib/offsite-requests.ts:433-445, :409, :382`; `tests/offsite-requests.test.ts:736-768, :761-764, :796-798`. A scan that only
reads the first `<link>`/`<image>`/`<use>` group (`if (gt === -1)`) passes all 142 tests; four others survive: reading only the
last start of a group, attributes capped at 64 characters, a single-space `\s+`, and a dropped lookahead on `</(?:style|svg|math)`
(`</svgx>`). In `<svg><style><link alt="a<b" rel="stylesheet" href=…>` the `<link>` is in the SVG namespace and the browser
fetches nothing, so the `<link>` legacy path is never tested on a fetched input.

### H9-03 [stage-1, low] The module header was not widened: **Fix now** (T38)

`src/lib/offsite-requests.ts:3-5`. It lists only a commented-out `<img>`, a script string and `<textarea>` text; G8-03(c) asked
for the spec §8 list. It omits the likeliest false positive on this site: Markdown inline code such as
`<img alt="x" src="https://…">` renders with raw quotes and is now reported by `legacyUrls`.

### H9-04 [stage-1, low] The 1 s wall-clock budget in the linear-time tests fails intermittently: **Fix now** (T38)

`tests/offsite-requests.test.ts:356-363, :866-882`. One of five full `npm test` runs failed at `:361`. Inputs of 1.0–1.4 MB take
0.4–0.5 s alone and pass 1 s next to the Astro build test, so "`npm test` clean" (which gates every publish) is not reliably
reproducible. A 4 s budget still catches a quadratic path (minutes at 1 MB).
